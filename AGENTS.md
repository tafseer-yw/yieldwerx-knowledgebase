# Agent instructions

## Scope

This repository stores internal YieldWerx knowledge and portable knowledge skills.

## Working rules

- Read `plugins/yieldwerx-knowledgebase/skills/ask-yieldwerx/references/INDEX.md`
  before reading handbook chapters.
- Open only the chapters needed for the task.
- Treat approved PRDs and durable product decisions as higher authority than the
  handbook.
- Do not invent missing behavior. Mark it as unconfirmed.
- Use simple language that a QA new to the module can understand.
- Keep one Markdown file per chapter or appendix.
- Preserve raw source documents and source hashes.
- Run `npm test` after changes.
- Do not commit generated ZIP files.
