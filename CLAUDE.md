# YieldWerx Knowledgebase instructions

Use the `ask-yieldwerx` skill for domain questions and the
`update-yieldwerx-knowledge` skill for approved knowledge changes.

Start from the knowledge index. Do not load the entire handbook. Cite source IDs and
section IDs for important product claims. Use plain language, explain abbreviations,
and clearly label anything not confirmed by the available sources.

For repository changes, follow `CONTRIBUTING.md`, preserve the raw source and catalog
entry, update only affected chapters, update `CHANGELOG.md`, and run `npm test`.
